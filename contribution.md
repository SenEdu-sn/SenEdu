# Conventions de contribution

## Branches
- `main` : toujours déployable, jamais de push direct.
- `feature/<sujet>`, `fix/<sujet>`, `chore/<sujet>`.

## Commits (format Conventional Commits)
- `feat:` nouvelle fonctionnalité
- `fix:` correction
- `chore:` maintenance, configuration
- `docs:` documentation

## Pull requests
- Une PR par sujet, petite et lisible.
- Relue et validée par l'autre associé avant fusion.
- Aucune clé d'API ni mot de passe dans le code (voir `.env.example`).
